A modern, interactive **Neo-Brutalist personal portfolio website** designed for a Data Analyst. Features dynamic 3D canvas animations, theme switching (Light/Dark mode), interactive custom cursor tracking, responsive card tilt effects, verified certifications, and showcase of data analytics projects.

---

## ✨ Features

- 🎨 **Neo-Brutalist Aesthetic**: Crisp typography, high-contrast borders, bold yellow accents (`#ffd83d`), and hard drop shadows.
- 🌊 **Interactive 3D Wave Mesh**: Canvas-based 3D grid in the hero section that flows smoothly and reacts to cursor movement with wave physics and glowing nodes.
- 🎯 **Custom Cursor & Tracking**: Smooth dual-ring cursor with trailing shadow, interactive hover states, and content fading.
- 🌓 **Light & Dark Theme Switcher**: Persisted color mode with instant seamless palette toggling.
- 🛠️ **Analytics Toolbox**: Tech stack showcase with brand icons for Python, Java, SQL, Excel, Power BI, Tableau, Pandas, NumPy, Matplotlib, MySQL, PostgreSQL, and Jupyter.
- 📜 **Certifications & Projects Showcase**: Detailed cards highlighting verified credentials and analytics project write-ups.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers.

## 🚀 Getting Started

### Method 1: Direct Browser Open
Simply double-click `index.html` or open it in any modern browser (Chrome, Safari, Firefox, Edge).

### Method 2: Python Local Server
If you prefer running a local HTTP server using Python:

```bash
# Clone the repository
git clone https://github.com/Kunaltab/my_portfolio.git

# Navigate into the project folder
cd my_portfolio

# Install requirements (optional, for live server tooling)
pip install -r requirements.txt

# Start the local server
python3 -m http.server 8000
```

Open your browser and navigate to `http://localhost:8000`.

## 🌐 Deployment (GitHub Pages)

To host this portfolio live on **GitHub Pages**:

1. Push your repository to GitHub.
2. Go to **Repository Settings** ➔ **Pages**.
3. Under **Build and deployment**, set Source to `Deploy from a branch`.
4. Select `main` branch and `/ (root)` folder.
5. Click **Save**. Your site will be published at `https://Kunaltab.github.io/my_portfolio/`.
